# Depth Camera Policy Mode

Status: ready-for-agent
Labels: enhancement, ready-for-agent

## Parent

## What to build

Add a `depth-camera` mode to the canonical hierarchical navigation entry point. This mode should feed camera-derived 24D navigation observations to the trained upper-level navigation actor while keeping the existing 24D policy interface unchanged. It should use camera-derived front clearance for the safety shield and should report oracle-vs-camera observation and action differences when oracle comparison data is available.

This slice is the first policy-facing D435 integration path.

## Acceptance criteria

- [x] The canonical entry point supports a `depth-camera` mode.
- [x] The mode creates the simulated D435 camera from config settings.
- [x] The mode translates camera depth data into the existing four obstacle slots.
- [x] The upper-level navigation actor receives camera-derived 24D observations.
- [x] The safety shield uses camera-derived front clearance.
- [x] The mode reports enough status to compare oracle and camera-derived observations/actions when oracle data is available.
- [x] The mode preserves the trained policy interfaces and does not retrain or reshape the navigation actor.
