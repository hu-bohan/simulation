# Depth Scan Debug Mode With Oracle Comparison

Status: ready-for-agent
Labels: enhancement, ready-for-agent

## Parent

`.scratch/d435-depth-camera-navigation/PRD.md`

## What to build

Add a `depth-scan-debug` mode to the canonical hierarchical navigation entry point. This mode should create the simulated D435 camera using config-driven camera parameters, compute camera-derived depth scans, compute oracle scans or oracle obstacle references, and report the difference between camera-derived perception and oracle geometry.

The mode should prioritize inspectability over policy performance. It should make it easy to compare simulated camera obstacle estimates with the known obstacle layout and produce video overlay visualization where practical.

## Acceptance criteria

- [x] The canonical entry point supports a `depth-scan-debug` mode.
- [x] The mode creates the simulated D435 camera from config settings.
- [x] The mode computes camera-derived scan data.
- [x] The mode computes oracle comparison data for fixed obstacle layouts.
- [x] The mode reports camera-vs-oracle obstacle position or clearance differences.
- [x] The mode can show or record video overlay with path, goal, oracle obstacles, and camera-derived perception where practical.
- [x] The mode does not need to feed camera-derived obstacle slots to the navigation actor.
